# 小名 1.0

「小名」是一个原创的 macOS 屏幕录制应用。名字来自作者的称呼，工程目录仍叫 `LJM`（姓名缩写）。它不是任何现成录屏产品的仿制品，也不使用别人的名称、图标或界面。

当前版本是 **1.0**（`CFBundleShortVersionString` 为 `1.0`，`CFBundleVersion` 为 `1`）。Bundle Identifier 是 `dev.ljm.recorder`。

## 1.0 实际能做的事

- 录制主显示器或自选显示器，也支持划区录制。控制条自己的窗口不会进画面。
- 用系统的 ScreenCaptureKit 采集系统声音，并可与麦克风混进同一条 AAC 音轨。默认系统声音开、麦克风关。不会安装虚拟声卡。
- 摄像头小窗：可选圆形或长方形，可拖动和缩放，位置会记住；它是桌面上的窗口，会被一起录进画面。
- 默认画质：长边最高 3840、30 fps。可选 1920 / 2560 / 3840，以及 60 fps。「省电」是可选项，打开后才会降到 1920@15；默认不会悄悄降低画质。
- 硬件 H.264 编码；画面几乎不变时不再拿去编码；按真实时间戳写入，保证音画对齐。
- 开录时默认会隐藏主控制条，在录制区域正中倒数 3、2、1 再开始。倒数、控制条和开始提示音都不会被录进去；倒数中再按一次录制可取消。
- 开始后出现精简录像条，默认在录制屏幕或选区的右下角。鼠标离开 5 秒后，条子会收成只剩暂停和停止；在非按钮区域停留 1.5 秒会展开。除按钮区外都可拖动。
- 暂停 / 继续（⌘⇧P）。暂停期间不走计时，也不计入自动停止。
- 停止后立即打开回看窗口：播放刚保存的文件，列出最近录像，可在访达中显示，或用系统分享面板分享。
- 自动缩放、光标高亮、点击涟漪、水印：都已实现，默认关闭。
- 设置里还可以开开始提示音、录制边框、录完自动播放、录完在访达中显示、自动停止（15 / 30 / 60 分钟），以及恢复默认设置。恢复默认不会清除保存文件夹书签，也不会忘掉控制条位置。
- 控制条可贴在屏幕四边，也可以放到任意位置。除按钮区外都可拖曳。鼠标进入按钮区会变成手指；顶端发光横线悬停是张开的手掌，按住是握拳；双击横线可以提起控制条。靠近屏幕边缘不会再额外缩小。
- 快捷键：⌘⇧R 开始或停止，⌘⇧P 暂停或继续，⌘⇧L 把控制条提到前面。

## 文件保存在哪

代码里的默认目录是：

```text
~/Movies/LJM/LJM-2026-11-15-20-31-02.mp4
```

文件名使用本地时间，精确到秒。写入时先写成 `*.partial.mp4`，成功后再改成最终的 `.mp4`。设置里可以改保存文件夹，选择会被存成安全作用域书签，下次还能写。不要随便清掉这个书签。

## 环境

- 一台 Mac，系统 **macOS 14 或更新**
- 命令行开发者工具（有 `swiftc` 即可）

不必安装完整 Xcode，也不必加入付费的 Apple 开发者计划。个人 ad-hoc 签名就能在本机运行。

## 如何编译

在项目根目录执行：

```bash
./build.sh
```

脚本会用 Swift 5 编译 `LJM/` 下的源码，把 `Info-build.plist` 和资源装进应用包，再用 ad-hoc 签名（`codesign --sign -`），identifier 为 `dev.ljm.recorder`。为了让屏幕录制权限在重新编译后通常还能保留，签名使用只绑定 bundle id 的 designated requirement。编好的应用在：

```text
build/小名.app
```

启动请用：

```bash
open "build/小名.app"
```

不要直接运行包里的可执行文件（`build/小名.app/Contents/MacOS/小名`），否则权限对话框和窗口行为可能不正常。

请只保留这一份可运行的 `.app`。不要再复制一份到桌面、下载文件夹或 `/tmp` 里长期存放，否则聚焦搜索可能打开旧版。校验签名时如果要复制到临时目录，用完请马上删除。

`LJM/Info.plist` 是早期设想用 Xcode 打开时留下的模板，当前构建不会用到它。真正写入应用包的是根目录的 `Info-build.plist`。`Assets.xcassets/AppIcon.appiconset` 目前只有清单、还没有图标文件；程序坞里会显示系统默认图标。

`LJM/Resources/MingWordmark.png` 和 `Sacramento-OFL.txt` 是 1.0 开发中探索标志时留下的素材，当前 `build.sh` 只会把 `XuanPaper` 和 `GlowRidges` 拷进应用包。

## 第一次使用：权限

画面和系统声音都走系统的「屏幕录制」权限。第一次打开后点录制，系统弹出提示时请允许，不要点拒绝。如果之前拒绝过，系统不会再弹窗，需要到：

**系统设置 → 隐私与安全性 → 屏幕与系统音频录制 → 打开小名**

然后完全退出「小名」，再重新打开一次。

麦克风和摄像头权限只会在你打开对应开关时申请，启动时不会主动要。

## 仓库里有什么

包含：`LJM/` 下的 Swift 源码、资源、`build.sh`、`Info-build.plist`、entitlements，以及 `docs/` 里的设计笔记。

不包含：编好的 `.app`、`test-output/`、备份文件（`*.bak*`）、编译中间产物、录像。别人拿到仓库后，在自己的 Mac 上运行 `./build.sh` 即可得到应用。
