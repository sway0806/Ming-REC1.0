# 录屏工具设置逻辑 · 蒸馏分析（为「小名」）

> 依据：用户提供的一款商用 Mac 录屏软件设置截图（只取思路，不照搬名称、图标、界面与文案）。
> 原则：小名保持自己的暗色 G 版视觉；默认画质不降（长边 3840 / 30fps，可选 60fps）。

## 1. 对方的系统逻辑（整理）

| 层 | 对方做法 | 背后的思路 |
|---|---|---|
| 录前面板 | 屏幕/区域、摄像头、系统声、麦克风四个开关；纯音频模式带电平；录制列表带计数；菜单栏菜单 | 「录什么」一眼可控；声音要看得见电平才敢录 |
| 录制中工具条 | 计时、当前文件大小 + 剩余磁盘、暂停/继续、停止、截图、标注开关；实时音量面板（系统/麦克风滑杆 + 静音） | 录制中最焦虑的是「在录吗、多大了、盘够吗、声音对吗」，直接给答案 |
| 实时标注 | 笔、矩形/椭圆、箭头、直线、荧光笔、马赛克、步骤序号、颜色、撤销/重做/清除、热键开关 | 教学/演示场景，画在屏幕上即被录入 |
| 录制设置 | 3 秒倒计时、开始提示音、录制边框、隐藏浮动条、浮动条不入画、GPU 加速、录完播放 | 降低误录与「忘了在录」；录完立刻确认结果 |
| 热键 | 开始/停止、暂停/继续、截图、标注 | 全程可不碰鼠标 |
| 视频/音频 | 格式、质量、帧率、可变/固定帧率、额外单独音频文件；音频格式/码率/采样率 | 给进阶用户选择，但默认值要合理 |
| 摄像头 | 设备、分辨率、位置预设、矩形/圆形、透明度、旋转/翻转、可选抠背景 | 画中画要「好看且不挡内容」 |
| 自动化 | 自动分段、自动停止、定时录制；关闭行为（最小化到菜单栏 / 退出）；恢复默认 | 长时间录制与无人值守 |
| 不取 | 付费墙/升级页、24fps 低默认、对方视觉与命名 | 小名默认 4K/30，界面自有风格 |

## 2. 小名现状对照

已有：屏幕/区域/多屏、系统声、麦克风（与系统声混音）、摄像头小窗（形状、拖动缩放、录入画面）、画质/帧率、省电、快捷键、文件夹与最近文件、计时、权限引导、光标高亮、点击涟漪、水印、自动缩放、分享、控制条不入画、双击移动/吸附。

缺口（按价值排序）：
1. **暂停/继续 + 热键**（长录必备）
2. **倒计时 + 开始提示音**（避免录到手忙脚乱的开头）
3. **录制边框**（明确「正在录哪里」）
4. **录制中状态：文件大小 + 剩余空间**（盘满焦虑）
5. **录完行为：自动播放 / 在访达显示**
6. **自动停止（时长）/ 自动分段**
7. **实时音量与静音**
8. **摄像头透明度 / 镜像翻转**
9. **恢复默认设置**
10. **关闭行为：最小化到菜单栏**
11. 实时标注（工作量大，放第二轮）
12. 额外单独音频文件、定时录制、抠背景（第三轮）

## 3. 第一轮落地原则

- 新增设置全部默认关闭或保持现有行为，**不改变默认画质与拖动/吸附手感**。
- 新界面元素沿用小名暗色 G 版卡片（SideCard）样式，不新增仿制图标。
- 暂停采用「丢弃暂停期间样本 + 时间轴平移」，保证音画同步。
- 每项都有自检或可观察的结果。
